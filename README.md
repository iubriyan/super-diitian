# CR GPT — ক্লাস রুটিন ও নোটিশ চ্যাটবট

CR GPT হলো তোমার ক্লাসের জন্য একটা ছোট চ্যাটবট, যেটা `data/routine.json` ফাইলে থাকা রুটিন ও নোটিশের ভিত্তিতে ক্লাসমেটদের প্রশ্নের উত্তর দেয় (Google-এর Gemini API ব্যবহার করে)।

## ⚠️ জরুরি নিরাপত্তা নোট

তুমি আগে যে API কী-টা শেয়ার করেছিলে, সেটা এখনই **রিজেনারেট/ডিলিট** করে ফেলো:
[Google AI Studio](https://aistudio.google.com/apikey) → পুরনো কী ডিলিট করো → নতুন একটা কী বানাও।

এই প্রজেক্টে কী **কখনো ফ্রন্টএন্ড কোডে (HTML/JS) বসানো হয় না** — কারণ ব্রাউজার থেকে যে কেউ "View Source" করে সেটা দেখে ফেলতে পারবে এবং তোমার নামে বিল/অপব্যবহার হতে পারে। এখানে কী শুধু সার্ভারের `.env` ফাইলে (গোপনে) থাকে, আর ব্যাকএন্ড (`server.js`) সেটা ব্যবহার করে Gemini API কল করে।

## ফোল্ডার গঠন

```
cr-gpt/
├── server.js          ← ব্যাকএন্ড, Gemini API কল করে (কী এখানে গোপনে থাকে)
├── data/routine.json  ← ক্লাস রুটিন ও নোটিশ (এটাই তোমার "ট্রেইনিং ডাটা")
├── public/            ← চ্যাট UI (HTML/CSS/JS)
├── .env.example       ← .env বানানোর নমুনা
└── package.json
```

## চালানোর ধাপ

১. [Node.js](https://nodejs.org) (ভার্সন ১৮ বা তার উপরে) ইনস্টল করো।

২. টার্মিনালে এই ফোল্ডারে গিয়ে ডিপেন্ডেন্সি ইনস্টল করো:
```bash
npm install
```

৩. `.env.example` ফাইলটার কপি বানাও এবং নাম দাও `.env`, তারপর ভেতরে তোমার **নতুন** Gemini API কী বসাও:
```bash
cp .env.example .env
```
```
GEMINI_API_KEY=তোমার_নতুন_কী
PORT=3000
```

৪. `data/routine.json` ফাইলটা খুলে তোমার ক্লাসের আসল রুটিন ও নোটিশ বসাও (নমুনা হিসেবে একটা কাঠামো দেওয়া আছে — একই ফরম্যাট মেনে দিন/বিষয়/সময়/রুম/শিক্ষকের নাম বদলে দাও)।

৫. সার্ভার চালু করো:
```bash
npm start
```

৬. ব্রাউজারে যাও: `http://localhost:3000`

## রুটিন আপডেট করা ("বটকে ট্রেইন করা")

আসলে এখানে মডেল ট্রেইন করার দরকার নেই — Gemini একটা রেডিমেড ভাষার মডেল, আমরা শুধু প্রতিটা প্রশ্নের সাথে `data/routine.json`-এর তথ্য জুড়ে দিই (`server.js`-এর `buildSystemPrompt` ফাংশনে), যাতে বট শুধু এই তথ্যের ভিত্তিতেই উত্তর দেয়। তাই রুটিন বদলালে বা নতুন নোটিশ দিলে শুধু `routine.json` ফাইলটা এডিট করে সার্ভার রিস্টার্ট করলেই হবে — কোনো কোড বদলানো লাগবে না।

## ইন্টারনেটে পাবলিশ করতে চাইলে

Render, Railway বা Vercel-এর মতো কোনো হোস্টিং সার্ভিসে ডিপ্লয় করতে পারো। প্রতিটাতেই "Environment Variables" নামে একটা অপশন থাকে — সেখানে `GEMINI_API_KEY` বসাবে (কখনো কোডে বা GitHub রিপোতে না)। GitHub-এ আপলোড করলে `.gitignore` ফাইলটা নিশ্চিত করে যে `.env` আপলোড হবে না, কিন্তু `data/routine.json`-এ ব্যক্তিগত/স্পর্শকাতর কিছু না রাখাই ভালো, কারণ সেটা সবার জন্য পাবলিক থাকবে।

## খরচ

Gemini API-এর ফ্রি টিয়ারে একটা নির্দিষ্ট পরিমাণ পর্যন্ত রিকোয়েস্ট ফ্রি — ক্লাসের সাধারণ ব্যবহারের জন্য এটা যথেষ্ট হওয়ার কথা। বেশি ব্যবহার হলে Google-এর pricing পেজ চেক করে নিও।
